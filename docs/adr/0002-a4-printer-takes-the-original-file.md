# A4 普通打印机拿原文件，不走标签那条路

状态：已采纳

gw 上除了标签机（CT-428D，TSPL 直写）还有一台 A4 普通打印机（EPSON，CUPS 队列）。非 Windows 上每台打印机带一个 `kind`：`label` 是标签机，`office` 是 A4 打印机；Windows 上的条目没有 `kind`。

- **文件原样交给 A4 打印机**（`printing.print_file`），按文件自身尺寸印在 A4 上，不走"栅格化再缩到标签纸"那条路。「标签纸」设置只管标签机。把栅格图送给 A4 打印机的调用会直接报错。
- **截图整张印在一页 A4 上**，给拣货的人拿着对照。永远走 A4 打印机，不看下拉里选的是谁：打标签时下拉一直停在标签机上。
- **ERP 打印桥只上报 `label`**，A4 打印机只给面板网页用，ERP 看不到它（2026-11-11 定）。
